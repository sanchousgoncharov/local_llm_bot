# 🤖 Telegram Bot с поддержкой контекста диалога на основе локальной LLM

Создание Telegram-бота с поддержкой контекста диалога на основе локально развернутой языковой модели.

## 🎯 Цель проекта

Научиться развертывать языковые модели с помощью LM Studio, создавать Telegram-ботов и реализовывать механизм управления контекстом диалога для обеспечения персонализированного взаимодействия с пользователем.

## ⚡ Быстрый старт

### Шаг 1: Подготовка языковой модели

1. **Установите** LM Studio
2. **Загрузите модель** на платформе Hugging Face:
   - Рекомендуемая модель: `Qwen2.5-1.5B-Instruct-GGUF`
   - Выбирайте небольшие инструктивные модели для лучшей производительности
3. **Запустите модель** в LM Studio и проверьте её работу в чат-интерфейсе

### Шаг 2: Настройка бота

1. **Создайте бота** через @BotFather в Telegram и получите API-токен.
3. **Создайте файл `.env`** и добавьте токен в формате TELEGRAM_BOT_TOKEN=your_token_here
4. **Установите библиотеки** из requirements.txt с помощью команды pip install -r requirements.txt
5. **Проверьте установленные пакеты** pip list
6. **Запустите бота** с помощью команды python bot.py
7. **Запустите Qwen2.5-1.5B-Instruct-GGUF** в LM Studio.

## Команды поддерживаемые ботом:
1. /start - вывод всех доступных команд
2. /model - выводит название используемой языковой модели
3. /clear - очистить историю диалога

## Демонстрация:
Ссылка на [демонстрационное видео](https://rutube.ru/video/private/4c072269b28943f06d095fc5d6387983/?p=HDlrVu6rorEDYWciBOWYPQ) работы Telegram-бота с поддержкой контекста на основе локальной LLM:
В видео продемонстрирована работа Telegram-бота с с поддержкой контекста на основе локальной LLM, а именно: 
1) **Работа бота.** Ответ бота на последовательные вопросы, используя контекст. 
2) **Многопользовательность.** История диалога сохраняется и обновляется для разных пользователей независимо. 
3) **Очистка контекста.** Использован /clear и показано, что бот «забыл» предыдущий разговор.
